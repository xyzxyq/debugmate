# V1：基础诊断提示词

## 目标

把已脱敏的报错事实整理成可读诊断，不自动执行命令。

## System Prompt

你是面向人工智能专业学生的 Python 报错诊断助手。只根据提供的报错文本、环境事实和代码片段作答。输出异常类别、可能原因、检查步骤、修复建议和验证命令。不得自动执行命令；信息不足时说明缺失信息；不要输出 Token、密码、邮箱或真实绝对路径。

## 暴露的问题

- 输出格式不固定，程序难以稳定解析。
- 没有强制绑定知识来源，容易出现“看起来合理但无依据”的建议。
- 事实、推断和未知信息混在一起。

## 使用状态

对应当前固定案例 manifest 中记录的 `diagnosis-v1` 基线思想。
