# DebugMate V0.1 讲解视频脚本

> 建议时长：5–7 分钟。录制时可按段落停顿并配合页面操作。

## 0:00–0:35 开场

大家好，我的《校外实训》项目是 DebugMate：面向人工智能专业学习场景的多模态报错诊断与复盘智能体。很多同学在学习 Python、PyTorch 或 CUDA 时，会把一整段报错直接复制给大模型，但得到的答案经常缺少环境依据，也可能给出未经确认的安装命令。DebugMate 想解决的不是“再做一个聊天框”，而是把一次报错整理成有证据、可检查、能说明不确定性的诊断过程。

## 0:35–1:15 项目目标与工具

本项目选择课程第二类，也就是大模型综合创意应用。核心成果包含专属知识库、完整工作流，以及文字、图像和语音三种输出。Dify 已实际验证知识库 readback 和严格 envelope；本地 Python 负责脱敏、严格数据校验、结果生成和页面展示。界面使用 Gradio，PNG 使用 Pillow 确定性绘制，语音使用 Windows SAPI 和 FFmpeg。V0.1 只定位为 Windows 本地课程演示，不宣称可以公网部署或生产使用。

## 1:15–2:00 知识库与隐私流程

知识库不是由大模型随意编写，而是自动整理了 17 个官方来源，覆盖 Python 异常与导入、pip 和虚拟环境、PyTorch 张量与 CUDA、NVIDIA 兼容性、Hugging Face、Ultralytics 以及 Windows 路径和 PowerShell。每个来源都保存标题、网址、适用版本和错误类别。

在输入侧，用户可以提交报错文本、截图、代码和环境信息。系统会先在本机识别 Token、邮箱、用户名和绝对路径等敏感内容，并生成脱敏预览。只有用户确认预览后，数据才允许进入后续诊断。这一设计对应作品中的“自动脱敏加上传前确认”，也避免真实个人信息进入截图、日志和 PPT。

## 2:00–2:45 提示词优化

提示词一共保留四个版本。V1 只要求给出类别、原因和步骤，问题是格式不稳定、依据不清。V2 增加 fact ID 和 evidence ID 绑定，把事实、推断和缺失信息分开。V3 强制输出 DiagnosisRecord JSON，并要求每条命令写明平台、影响、预期结果和回退方式。V4 进一步约束中文解释、英文错误原文、语音复盘长度和多模态一致性。优化方向不是让答案更长，而是让答案能够被程序校验，并且可以从同一个对象稳定生成报告、图片和语音。

## 2:45–4:10 完整演示

现在进入工作台。我输入 ModuleNotFoundError 案例并先生成脱敏预览。Dify 正常时页面显示实时诊断；本次录制若遇到云端超时，页面明确显示“本地降级”，说明这不是伪装的云端实时调用。左侧是脱敏后的输入和抽取字段，中间显示错误类别、置信度、事实与证据。

右侧是三模态结果。文字报告包含观察事实、原因、不确定性、检查、修复和验证步骤。诊断卡 PNG 由相同的结构化诊断数据绘制，不使用图像生成模型，所以不会把命令或证据画错。语音复盘使用同一个 recap_text 生成，内容与报告结论一致。最后可以下载 ZIP，里面包含诊断 JSON、报告、PNG、MP3、引用、manifest 和校验值。自动化测试还验证了 ZIP 内的来源运行 ID 与页面显示的是同一次结果。

接下来展示部分完成状态。当语音生成失败时，系统不会把整个流程显示成成功，而是保留报告和诊断卡，明确失败节点、安全错误码和“只重试语音”的范围。诊断卡失败时也是一样，已有文字和语音仍可使用。这体现了大模型应用需要诚实呈现失败，而不是只展示最好看的成功页面。

## 4:10–4:50 工程验证

为了保证课程演示稳定，我使用 pytest 和真实 Microsoft Edge 做了代表性验证，包括键盘操作、状态播报、百分之二百缩放、长报告与长命令、成功和失败状态辨识，以及浏览器真实下载。当前界面相关的 58 个单元与状态测试通过，报告、PNG、MP3 和结果模块的 264 个测试通过，代表性 Edge 场景也已经逐项运行。课程证据目录保存三张当前版本截图和 SHA-256 清单，所有图片都来自真实运行。

## 4:50–5:35 局限与改进

V0.1 仍有明确局限。第一，稳定录制路径以本地规则和固定回放为主，Dify 在线视觉、知识库和 TTS 会受到账号、额度和模型 provider 的影响。第二，目前只有少量代表性案例，不能证明覆盖所有 Python 和 AI 工程错误。第三，本地 SAPI 音频虽然已经通过文件、解码和非静音检查，正式录屏前仍需要人工试听一次。后续可以补充 Dify 的真实在线探针、增加 CUDA 显存和张量形状案例，并根据实际评测继续优化 V4 提示词。

## 5:35–5:55 总结

总结来说，DebugMate V0.1 完成了从多模态输入、隐私确认、专属知识检索、结构化诊断，到文字、PNG、MP3 和结果包下载的课程演示闭环，并诚实区分 Dify live、local fallback 和固定回放。它的重点不是替代工程师，而是帮助 AI 专业学生把一次报错变成有依据、可执行、可复盘的学习过程。谢谢大家。
