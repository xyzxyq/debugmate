# DebugMate V0.1 课程演示版范围设计

## 定位

DebugMate V0.1 是《校外实训》的本机课程演示作品，不是公开部署、商业交付或生产服务。目标是在 Windows 浏览器中稳定演示一次可追溯的 AI/Python 报错诊断，并提供足够真实证据支撑 PPT 与讲解视频。

## V0.1 必须完成

1. 本机 Gradio 页面可使用固定回放案例，并保留一条已脱敏本地输入路径。
2. 同一次结构化诊断派生四类成果：文字报告、PNG 诊断卡、MP3 语音复盘、ZIP 结果包。
3. 保留专属知识源、来源清单、提示词版本和工作流说明；Dify/LLM 是课程说明中的增强诊断路径，本地确定性回放是稳定演示降级路径。
4. 保留上传前脱敏预览、结果身份关联和真实运行证据，不使用生成图片伪造运行截图。
5. 准备 3–5 个代表性案例，覆盖成功、部分降级和安全失败即可。
6. 生成课程交付材料：项目说明、真实截图、PPT、超过 3 分钟的讲解视频脚本与素材清单。

## 明确不做

- 公网部署、域名、账号体系、并发、监控、SLA 和长期运维。
- 移动端原生适配、跨浏览器穷举和跨平台支持。
- 15 项视觉矩阵每项都作为阻塞门槛。
- immutable generation、双重原子指针、全故障点事务回滚和残留恢复矩阵。
- 对 ZIP、文件名、响应头和所有攻击变体进行浏览器层穷举；保留已有严格服务端校验和一个正向下载验收即可。
- Dify Cloud 的生产可用性、额度耗尽恢复和完整云端迁移演练。

## 最小架构

输入或固定案例经过脱敏确认后，进入结构化诊断工作流。工作流输出一个受 Pydantic 校验的诊断对象；本地结果层从该对象生成报告、诊断卡、复盘文本、音频与下载包；Gradio 只负责统一展示。Git 保存知识源、提示词、固定案例和课程证据。

## 验收方式

- 自动测试：组件测试全绿；浏览器只保留桌面完成态、长内容、键盘可达、200% 等效缩放和一个降级/失败代表场景。
- 下载：点击一个完整 ZIP，确认可打开、manifest 与可见运行身份一致。
- 多模态：报告、PNG、MP3 均来自同一诊断对象，能在页面展示并下载。
- 课程材料：截图均来自真实运行；PPT 和视频完整解释工具、提示词、知识库、工作流、问题与改进。

## 完工顺序

1. 收尾当前 UI 可达性改动并做一次代表性回归。
2. 做最小下载正向验收，不扩展攻击矩阵。
3. 生成 3–5 个可复现案例和课程截图。
4. 整理项目说明、PPT 与视频脚本。
5. 进行一次本机端到端彩排，修复阻塞演示的问题后封版 V0.1。
