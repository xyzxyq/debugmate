## Trust Boundaries

| Boundary | Description |
|---|---|
| native form → local callback | Raw text and one upload reference first enter trusted local processing. |
| server presentation → browser DOM | Only redacted values and read-only capabilities may cross. |
| browser token → approval/diagnosis | One opaque token requests atomic server-side approval. |
| replay controls → live authority | Replay must not reuse or preserve a live token. |

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
