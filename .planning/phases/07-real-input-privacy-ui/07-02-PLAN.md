<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| OCR/redaction → preview | Image findings cross into the user-visible, signable preview contract. |
| browser token → server store | An untrusted opaque token requests approval of a server-owned strict preview. |
| concurrent callbacks → session authority | Edit, preview, approve and replay events can arrive in adversarial order. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---:|---|---|---|
| T-07-RACE | Tampering / EoP | high | `LocalPreviewStore` | mitigate/block | Monotonic revision plus lock-atomic publish-if-current and compare-and-pop consume; exhaustive threaded event-order tests. |
| T-07-SESSION | Spoofing | high | preview token | mitigate/block | Random token bound to request session, revision and TTL; copied/tampered/reused tokens fail closed. |
| T-07-OCR-AUDIT | Repudiation / Disclosure | high | `PreviewBundle` | mitigate/block | Value-free screenshot audit is signed through preview hash; OCR text, boxes and paths are excluded. |
| T-07-STORE-DOS | Denial of Service | medium | bounded store | mitigate | Deterministic max entries, per-session invalidation and expiry purge. |
</threat_model>
