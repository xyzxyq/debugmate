<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Environment config → bearer request origin | A malicious base URL could steal the app key. |
| Approved screenshot → upload API | File replacement or MIME confusion could bypass consent. |
| Dify response → JSON parser | Body/status/trace are untrusted and potentially oversized. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-08-ORIGIN | Spoofing/Information disclosure | settings/adapter | mitigate | Exact HTTPS origin, no redirects/userinfo/query/fragment; origin tests. |
| T-08-UPLOAD | Tampering | gateway/upload | mitigate | Root confinement, rehash, immutable bytes, decode/MIME equality; TOCTOU tests. |
| T-08-DUPLICATE | Tampering/DoS | workflow POST | mitigate | Connect-only retry and ambiguity classification; dispatch-count tests. |
| T-08-CITATION | Tampering | DSL retrieval trace | mitigate | Direct retrieval result sanitizer and same envelope; static DSL tests. |
| T-08-SIZE | DoS | response parser | mitigate | 512 KiB pre-parse cap and bounded trace models. |
| T-08-LEAK | Information disclosure | errors/results | mitigate | Fingerprint IDs and forbid body/header/key interpolation; safe-error tests. |
</threat_model>
