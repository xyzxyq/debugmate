<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| One-time approval → outbound side effect | Consent must be consumed and durably receipted before dispatch. |
| Dify envelope → DiagnosisRunOutcome | Provider facts, citations, commands and JSON are untrusted. |
| Accepted outcome → result publication | Invalid or stale results must never expose artifacts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-08-DUPLICATE | Tampering/DoS | live workflow/receipt | mitigate | One-time consume, started-before-dispatch and terminal receipt tests. |
| T-08-INJECTION | Tampering/Elevation | envelope/diagnosis | mitigate | Treat content as data; strict fact/evidence/command/privacy validation and terminal unsafe tests. |
| T-08-CITATION | Tampering | retrieval binding | mitigate | Direct trace + source/build/locator equality; forged/stale tests. |
| T-08-RACE | Tampering | service/outcome store | mitigate | Existing per-case lock/current lease plus receipt identity and immutable store. |
| T-08-LEAK | Information disclosure | repair/failure/evidence | mitigate | Allowlisted issue payloads, fingerprint IDs and secret/raw-body scans. |
</threat_model>
