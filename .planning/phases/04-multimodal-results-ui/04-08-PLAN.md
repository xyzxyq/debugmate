<objective>
Repair only the real Gradio layout collapse recorded as GAP-01, preserve its
original failing evidence, and establish a single-owner Edge harness. This is
deliberately not a semantic VQ-01 or VQ-01..15 closure plan: the current
loopback service has `workflow=None` and no approved live input, so it cannot
truthfully yield `completed + live`.

nested Gradio wrappers. Replace it with one unique grid identity, verify real
desktop geometry in Edge, and retain replay as a controlled, explicitly
labelled path. A later plan owns the local-rule live workflow and only then may
the full VQ matrix replace the current VQ-01 acceptance evidence.
</objective>
