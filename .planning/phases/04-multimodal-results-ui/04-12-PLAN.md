# Phase 04-12: V0.1 代表性验收与课程交接

## Objective

用少量真实案例确认课程演示闭环可用，并把成果直接交给评测摘要和课程材料阶段。该计划不是生产发布门禁。

## Tasks

1. 运行默认单元测试和与演示有关的代表性 Edge 测试；不要求完整 15 行视觉矩阵。
2. 检查一个完成案例和一个降级/失败案例的报告、PNG、MP3、ZIP 是否真实可打开。
3. 检查课程证据目录无占位符、无明显敏感信息，截图来自真实运行。
4. 在 `04-VERIFICATION.md` 记录“课程 V0.1 可演示 / 尚有限制”，而不是生产就绪结论。
5. 同步 REQUIREMENTS、ROADMAP 与 STATE，并把下一阶段改为小型评测摘要。

## Explicitly Deferred

- 公网部署、账户、权限、监控、SLA、并发与跨平台适配。
- 完整 VQ-01..15 发布门禁和不可变证据 generation。
- 原子 pointer、故障注入、恶意 ZIP/浏览器攻击矩阵。
- Dify、edge TTS 等外部平台必须在线才能演示的要求。

## Done When

本地演示路径和代表性成果已经过真实检查，已知限制写清楚，后续工作只剩小型案例/提示词说明以及 PPT、讲解稿和视频素材。
