  <files>.git/config</files>
  <action>Run `git status --short`, `git branch --show-current`, `git remote -v`, and `git rev-parse HEAD` to reconfirm that `master` is clean and no `origin` is present. Check `gh repo view {login}/debugmate` and proceed only when the name is available. If it already exists, stop before changing Git configuration and report whether it is private and whether its history can safely be reconciled.</action>

    <automated>git status --short; git branch --show-current; git remote get-url origin 2>$null; gh auth status; gh api user --jq .login</automated>
  </verify>
  <done>The executor has an authenticated GitHub account, a clean local `master`, no conflicting origin, and a confirmed target repository name.</done>

<task type="auto">
  <name>Task 2: Create the private remote, push master, and prove synchronization</name>
  <files>.git/config</files>
  <action>Create `{authenticated-login}/debugmate` with `gh repo create debugmate --private --source . --remote origin --push`. This must create a private repository; do not use a public visibility flag and do not initialize it with a README, license, or .gitignore that would create unrelated remote history. Confirm `origin` uses the expected GitHub repository URL, `git ls-remote --heads origin master` returns a ref, and its SHA equals local `git rev-parse HEAD`. Confirm visibility with `gh repo view {login}/debugmate --json nameWithOwner,visibility,isPrivate,url` and verify the local branch tracks `origin/master`.</action>
  <verify>
    <automated>$local = git rev-parse HEAD; $remote = (git ls-remote --heads origin master).Split([char]9)[0]; if ($local -ne $remote) { throw "origin/master does not match local master" }; gh repo view "$(gh api user --jq .login)/debugmate" --json nameWithOwner,visibility,isPrivate,url; git status --short; git branch -vv</automated>
  </verify>
  <done>A private `debugmate` repository exists for the authenticated account, `origin` is configured, local `master` tracks `origin/master`, and both point to the same commit.</done>
</task>
