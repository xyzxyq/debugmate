## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Result state/record → presentation | 只有严格 `ResultViewState` 与 `DiagnosisRecord` 可决定状态、摘要、权限和恢复信息。 |
| Browser → callbacks | 预览 token、fixture、纠错 draft、retry identity 和下载请求均跨越不可信浏览器边界。 |
| Manifest → native media/download | 页面只能展示重新验证的 manifest 成员与 session-owned capability URL，不能接受用户路径。 |
| Runtime UI → screenshot evidence | 截图必须来自当前代码的真实 Edge 运行且输入已脱敏，不能伪造或泄密。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-Q-UF9-01 | Spoofing | live/replay/fallback 状态 | mitigate | 保留文字+图标+状态色、fixture/source identity 与 backend/fallback 原因；禁止把 replay 或降级包装为 live 成功。 |
| T-Q-UF9-02 | Tampering | preview/correction/retry callbacks | mitigate | 保留一次性 token、二次确认、严格 draft、新运行身份与 server-owned retry scope；非法、重复和跨 session 输入 fail closed。 |
| T-Q-UF9-03 | Information disclosure | 技术详情与截图 | mitigate | 仅显示已验证脱敏信息；不渲染绝对路径、raw traceback/provider body、secret 或裸 capability；截图使用虚构脱敏案例。 |
| T-Q-UF9-04 | Elevation of privilege | 命令与下载表面 | mitigate | 命令保持只读且无 shell/安装回调；下载继续 manifest allowlist 重验证，不增加路径 textbox 或任意文件浏览。 |
| T-Q-UF9-05 | Repudiation | partial/failed/身份后置 | mitigate | 渐进披露仍保留完整身份、七字段恢复、安全错误码、可用/缺失产物与 retry 权限，不因降噪删除审计事实。 |
| T-Q-UF9-06 | Denial of service | 重复诊断操作 | mitigate | running 时继续禁用诊断、回放、纠错与 retry，保持既有队列和幂等语义。 |
